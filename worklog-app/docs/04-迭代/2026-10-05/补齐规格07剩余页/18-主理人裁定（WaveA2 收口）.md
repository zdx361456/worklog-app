## §3 MIN-01 `records_page.dart` 默认标题成孤值 —— **成立，已随 MAJ-01 同批修**

`records_page.dart:42` 原为 `this.title = '明细', // 与本波 MainShell 第 2 个 Tab 标签一致`。
`09-WaveA-实现设计.md:234` 的设计注释**原文**已预言：

> `this.title = '明细',                // m12：与本波 MainShell 第 2 个 Tab 标签「明细」(main.dart:207) 一致；**A2 换 Tab 后该默认值随之消失**

**裁定**：A2 既已把第 2 个 Tab 换成「日历」，且本页**最后一处无参构造点**（`main.dart` 的 `case Routes.records` → `const RecordsPage()`，全工程唯一）**已随 MAJ-01 同批删除** → 默认值**再无任何调用方依赖** → 按设计原意**移除**，改为 `required this.title`。
**为什么不保留默认值**：留着它意味着"漏传 `title` 即静默得到一个语义错误的标题"（`'明细'` 已不对应任何 Tab）——这正是本项目反复出现的**不实注释 / 静默错值**模式。

## §4 MIN-02 `AC-A2-05` 上游自相矛盾 —— **成立；实现取括注口径**

`02 §D.15` 的 `AC-A2-05` 行**原文**（同一格内前后矛盾）：

> `_pages` 4 项同建（`IndexedStack` 首帧 build 全部）→ 启动期 DB 读数由 1 增至 4；**确认无 ANR / 明显卡顿**（占位页 `_load()` 应为空实现）

- **主句**说「读数由 1 增至 4」；**括注**要求「占位页 `_load()` 应为空实现」——若括注成立，则读数**不增加**，主句不成立。

**裁定**：**实现取括注口径**（三占位页 `_load()` 为空实现 → 启动期 DB 读数**不增加**，仍只有 P01 一路）。
理由：括注是**可施工的要求**（"应为空实现"），主句只是**若不那样做的风险描述**；且 `AC-A2-01` 已要求"切换不崩"，空 `_load()` 是达成它的最省路径。
**登记 R34**：要求上游把 `AC-A2-05` 主句改写为条件式（"**若**占位页非空实现**则**读数由 1 增至 4"），消除歧义。
